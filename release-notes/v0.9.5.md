## 新功能：连接列表

主窗口底部新增“连接”。实时显示每个连接属于哪个程序、目标地址、走的是**直连**还是 **VPN**，以及**为什么**（例如“由名单里的 cmd.exe 启动，随它直连”）。

- 可以按“只看直连 / 只看走 VPN / IPv6 拦截”筛选，也可以搜索程序、地址、域名
- 国内 DNS 查询过的目标会显示域名
- 可以暂停刷新、复制选中的行（粘贴到 Excel 里就是表格）
- “加了程序但还是走 VPN”这类问题，先看这里最快

## 性能

打开多个直连程序（微信、抖音、浏览器等）时，新连接的第一个包不再排队等待：

- 已经认得的程序，新连接当场判断，不再交给后台线程排队
- 新启动的程序，用系统的进程快照查父进程，比原来逐层查询快得多
- 启动时先读一次 UDP 连接表，减少之后反复扫描连接表
- 日志里的 `[性能]` 行会显示“当场判断 N 个”，正常使用时一般不会出现

## New: connection list

The new **连接** button at the bottom of the main window shows every connection live: which program it belongs to, the destination, whether it goes **direct** or through the **VPN**, and **why**. Filter by direct / VPN / IPv6, search by program, address or domain, pause, and copy rows. Domains are shown for destinations the local resolver has looked up.

## Performance

New connections from programs SplitDirect already knows are now decided on the spot instead of waiting in a queue, parent-process lookups use a process snapshot instead of per-level queries, and the UDP connection table is read once at start. With several bypassed programs running you should no longer see the `[性能]` queue warning in the log.
